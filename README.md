# The Resonating Hall

Bilingual roster and team tracker for **AFK Arena Classic**. Record the heroes you own, their ascension and investments, and save formations by mode. All data stays in your browser.

## Features

- 255-hero AFK Arena Classic catalog generated from the community `afk-mine` CDN, with the five real classes resolved from public hero databases.
- Roster with ascension, level, Resonating Crystal, Signature Item, Furniture, Engraving, gear and notes.
- Hero detail drawer with portrait, investment summary, gear, artifact/collection and notes.
- Gear tracking with Mythic/T1-T5 tiers, stars, faction, resonant gear and exclusive gear.
- Dimensional hero links and artifact assignments.
- 22 artifacts: the seven Dura artifacts and fifteen class artifacts restricted by hero class.
- 23 collections with class restrictions, level 0-10, skill level 0-3 and mythic stats 0-8.
- Artifacts and collections are mutually exclusive; switching keeps collection progress saved.
- Search and filters by faction, class, ascension and role.
- Saved teams with a 2-front, 3-back formation, mode and notes, including drag-and-drop hero placement.
- 30 pets (Beasts) with their three Attribute Buffs, derived beast level and training, a player-set beast resonance level that flags pets below it with a pending `+N` badge, and one pet assignable per saved team.
- Versioned JSON export and validated import.
- English and Spanish interface, with game terms kept in English.
- Responsive dark “The Resonating Hall” design with framed hero icons.

## Stack

React 19, TypeScript, Vite, Tailwind CSS v4, Zustand, Zod, i18next, Radix UI and Vitest.

## Data

The hero catalog is generated from `https://raw.githubusercontent.com/afk-mine/cdn/main/unit.json` and stored in `src/data/heroes.json`. Hero icons are loaded from the `afk-mine` CDN at runtime. Artifact and collection artwork is loaded from `https://www.afk.global` at runtime.

The `class` field in `heroes.json` is the hero type (Warrior/Ranger/Mage). Real classes (Warrior/Tank/Ranger/Mage/Support) live in `src/data/hero-classes.json` and are generated by `npm run sync:hero-classes` from `https://www.afk.global/afk-arena/characters` with `https://gacha-data.com/afk-arena/characters/` as fallback. Artifact and collection catalogs are maintained in `src/features/artifacts/artifacts.ts` and `src/features/collections/collections.ts`. The 30-pet beast catalog lives in `src/features/pets/pets.ts`; pet artwork is loaded from `https://www.afk.global/images/afk-arena/game/beast/` at runtime.

## Deployment

### GitHub Pages

`.github/workflows/deploy.yml` typechecks, lints, tests and builds the app, then deploys `dist` to GitHub Pages. Enable Pages with **GitHub Actions** as the source. The workflow sets the Vite base path from the repository name automatically.

### Docker

```bash
docker compose up --build
```

Open `http://localhost:8080`. The image builds the static app and serves it with nginx. Override `VITE_BASE_PATH` at build time if the app is hosted under a subpath.

## Storage

- App data: `localStorage` key `afk-astral-codex:data`.
- Language preference: `localStorage` key `afk-astral-codex:lang`.
- Routing uses `HashRouter`, so static hosting needs no server rewrites.
